# DV-8 分段录制台

浏览器端的分段录像工具，仿复古摄像机造型，支持分段录制、滤镜/美颜、提词、字幕导出等功能。

## 文件结构

```
index.html   页面结构（HTML）
style.css    所有样式（复古机身、屏幕、按钮等设计相关的变量都在这里）
script.js    全部功能逻辑（录制、滤镜、提词、导出、存档等）
```

三个文件放在同一目录即可，`index.html` 通过相对路径引用另外两个文件，不需要额外配置。

## 本地预览

不能直接双击 `index.html` 打开（浏览器的摄像头权限在 `file://` 协议下会被拦截），需要用本地服务器打开，例如：

```bash
# 在这个目录下执行任意一种
python3 -m http.server 8000
# 或
npx serve .
```

然后浏览器打开 `http://localhost:8000`。

## 部署到 GitHub Pages

1. 把 `index.html`、`style.css`、`script.js` 三个文件放进一个 GitHub 仓库（可以直接放根目录，也可以放进 `docs/` 目录）。
2. 仓库 Settings → Pages，Source 选对应分支和目录。
3. 保存后几分钟内即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。

存档功能会自动识别当前环境：如果有自定义的 `window.storage`（例如放在支持这个接口的平台里）就用它，否则退回到浏览器自带的 `localStorage`，设置只存在这台设备的这个浏览器里，换设备需要用页面里的"导出设置 / 导入设置"按钮迁移。

## 调整设计

`style.css` 顶部 `:root` 里集中放了机身颜色、屏幕颜色、圆角、间距、字体这些变量，改这里就能整体调风格，不需要去翻后面的具体规则。
